# 商品影棚 · 精选代码快照

商品影棚是商品内容运营工作台。本仓库是从原项目某个提交中**显式筛选的独立代码快照**，没有原私有仓库的提交历史、培训资料或历史运行数据。它保留商品事实、抖音/小红书活动、生成流水线、人工版本审核、已审素材导出、发布安排与可暂停的运营计划，以及原有生图入口。

使用流程：录入自家商品与已确认事实 → 可选来源参考 → 选择平台并创建活动 → 查看结果和质检 → 人工审核 → 导出素材或安排发布。来源信息不会自动变成商品事实；导出不等于发布，计划不会自动批准或发布。详细步骤见[运营指南](docs/operator-guide.md)。

## 本地起步

需要 PowerShell 7.4+ 和 Docker Compose v2。只在隔离的本机使用；核对端口、持久卷和秘密文件位置后，从仓库根目录执行：

```powershell
./deploy/stack.ps1 init
# 检查 deploy/stack.env 和 deploy/secrets/；不要提交或公开实际秘密。
./deploy/stack.ps1 up
./deploy/stack.ps1 smoke
```

`init` 仅补齐缺失的本地配置，不覆盖已存在的同名文件。空库 `up` 迁移至 `0014_operation_plans`；已有数据库不要当空库迁移。`smoke` 只检查依赖、schema 和前端入口，不证明登录、媒体或外部连接可用。完整条件见[部署说明](docs/deployment.md)，前后端源码开发分别见[前端](frontend/README.md)和[后端](backend/README.md)。

**不要公网部署此快照。**空用户库启动会自动建立固定演示账号，`APP_ENV=production` 也不会跳过。发布与 OAuth 开关在本地 Compose 固定关闭，模型密钥未注入；生成、旧生图、发布 Worker 和计划调度器默认关闭。来源、模型、抖音真实 OAuth/上传/创建与平台公开结果均未在真实平台联调；小红书服务端发布待接入。没有连接时应显示待连接，不制造榜单、账号、内容或效果数据。待安全初始化、权限、HTTPS、秘密管理、上游连接和实际验收完成后才能重新评估部署范围。

## 实现与验证边界

前端使用 Vue 3、Vite、Element Plus；后端使用 FastAPI、SQLAlchemy、Alembic、PostgreSQL、Redis 和 MinIO。公开快照保留了应用、迁移、部署脚本和测试，但**不包含**原私有 0013→0014 升级所需的旧发布提交、备份、密钥和历史证据。因此只提供 `0014` 空库首次启动说明，不能照搬私有历史恢复流程。

原私有项目有按日期留存的隔离测试记录，但其测试媒体与营销模板已在此快照替换，历史结果不能直接迁移为公开版的通过结论，也不代表当前 CI 或真实上游已通过。快照的实际检查及范围见[验证记录](docs/verification.md)；导出来源与改写摘要见[快照清单](PUBLIC_EXPORT_MANIFEST.json)。
